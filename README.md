# Lovable Migrator

Ferramenta para analisar projetos exportados do Lovable e preparar sua migração para uma infraestrutura independente.

## Objetivos iniciais

- Inspecionar a estrutura do projeto sem executar seu código.
- Identificar migrações SQL e Supabase Edge Functions.
- Mapear nomes de variáveis de ambiente sem expor seus valores.
- Gerar um relatório JSON para orientar a migração.

## Segurança

A análise é somente leitura. Não altera o projeto analisado nem executa comandos do projeto.

## Status

Projeto em fase inicial de desenvolvimento.
